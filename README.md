# 🎓 Student Management System

An Excel-based **Student Management System** developed using Microsoft Excel, VBA (Visual Basic for Applications), PivotTables, PivotCharts, and an interactive dashboard to simplify student record management and administrative data analysis.

The project combines automated data entry, centralized record management, and visual reporting in a single Excel workbook.

---

## 📌 Project Overview

The Student Management System is designed to manage essential academic and administrative information efficiently. It allows users to maintain student records, track attendance, manage examination marks, record fee transactions, and analyze data through reports and a dashboard.

The project demonstrates the practical application of Excel functions, VBA automation, PivotTables, charts, and data visualization.

---

## ✨ Features

### 👨‍🎓 1. Student Database
- Maintain student information in a centralized database.
- Store student IDs, names, personal details, class, section, and admission information.
- Organize student records for easy access and management.

### 📅 2. Attendance Management
- Select students based on class and section.
- Enter and record student attendance.
- Maintain a separate attendance database for historical records.

### 📊 3. Marks Management
- Record examination marks for multiple subjects.
- Automatically calculate total marks and percentages.
- Assign grades and determine pass/fail results.
- Organize academic performance data for analysis.

### 💰 4. Fee Management
- Maintain student fee records.
- Record total fees, payments, pending amounts, and payment dates.
- Track payment status for better fee management.

### 📈 5. Reports
- Generate reports using Excel PivotTables.
- Summarize student information and administrative data.
- Analyze academic performance and fee-related information.

### 📉 6. Interactive Dashboard
- Display key performance indicators (KPIs).
- Visualize student, academic, and fee-related information using charts.
- Present important information in a centralized dashboard.

### ⚙️ 7. VBA Automation
- Automate selected data-entry and record-management tasks.
- Reduce repetitive manual work.
- Improve consistency in saving and organizing records.

## 📂 Workbook Structure

The workbook contains the following main worksheets:

| Worksheet | Purpose |
|---|---|
| `StudentDatabase` | Stores student information and records. |
| `AttendanceEntry` | Provides an interface for entering student attendance. |
| `AttendanceDatabase` | Stores attendance records. |
| `MarksEntry` | Provides an interface for entering examination marks. |
| `MarksDatabase` | Stores examination marks and calculated academic results. |
| `FeeEntry` | Provides an interface for entering fee transactions. |
| `FeeRecords` | Stores student fee and payment records. |
| `Reports` | Contains PivotTables used for reporting and analysis. |
| `Dashboard` | Presents KPIs and visual summaries of the available data. |

*Note: Worksheet functionality depends on the workbook's current configuration.*

## 🚀 How to Use

1. **Download or clone** this repository to your computer.
2. Locate the Excel workbook (`.xlsm`).
3. Open the workbook using **Microsoft Excel desktop application**.
4. Enable macros so that VBAs can do their tasks.
5. Navigate through the worksheets to manage student records, attendance, examination marks, and fee transactions.
6. Use the Reports and Dashboard worksheets to explore available summaries and visualizations.

---

## ⚠️ Important: Open in Microsoft Excel

**This project must be opened in Microsoft Excel for proper functionality.**

The workbook uses VBA macros, Excel-specific features, PivotTables, PivotCharts, and other Excel functionality that may not work correctly in web-based spreadsheet viewers or alternative spreadsheet applications.

For the best experience, open the downloaded workbook directly in the Microsoft Excel desktop application.
